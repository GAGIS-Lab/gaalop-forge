# QCA 概率可视化与 Q bit GA 核查

2026-09-16。QCA 可视化接入范围为 1–3 qubit，沿用三个 GAALOPScript 编辑区和既有概率图组件。

## 数学约定

参考作者的 [QCA 论文](https://arxiv.org/html/2606.17621v1)，采用真空 P=∏(f_k f_kT)，计算基态 ket_b=(f1T)^b1…(fnT)^bn P，位串顺序为 b1…bn。复振幅写作 a+j b，j=ei1*ei2。论文 v1 早期辅助度规的写法与当前上游修复不一致；实现使用当前代码的 ei1²=ei2²=+1，因此 j²=-1，不复制旧符号错误。

TBA 输出是 Witt 外积基底下的标量系数。解码器单独编译各 ket 和 j*ket，检查系数列正交性，按各列自身平方范数求坐标，不能套用 QRA 的统一缩放系数。重建后保留系数空间残差；概率为实、虚振幅平方和，不强制归一化。

## 执行路径

- 代码生成仍从主脚本符号编译，保留自由参数。
- 可视化另行编译“赋值 + 主脚本 + 可视化脚本”，在 Java 中求值优化后的标量表达式，不执行生成的 Java/Python/C++ 源码。
- 只投影冒号标记的变量，支持可视化脚本内先赋值再标记、多变量、三种输出模式。
- 无参数定值、未知状态、非有限数值及不支持的控制流会报错。当前可视化求值支持直线脚本、基础算术和常用标量数学函数，不声称支持所有 GAALOPScript 控制结构。
- QCA 不需要 QRA 原生库。旧 QCA 草稿保留，不自动替换为新的量子态示例；旧草稿可手动调整后启用可视化模式。

## Q bit GA 的未解决问题

当前项目的 qga/definition.csv 定义固定 Cl(6,3)，macros.clu 包含点、球、椭球和柱面构造，Ganja 的 AlgebraQGA 也按三维曲面处理。

[AGACSE 2024 GAALOPWeb 展示资料](https://staff.fnwi.uva.nl/l.dorst/AGACSE2024/SLIDES/Franchini_slides.pdf) 的量子位入口标注 Quantum Bit GA (2n,2n,0)，与当前 qga 资源不同。这是资源对应关系待核对的证据，不能仅凭相同缩写认定当前资源就是论文中的量子位代数。本次保留已有编译能力，不改写该代数或套用 QCA/QRA 解码规则。需要定位相应 Quantum Bit GA 版本的代数生成代码和量子态示例后再接入概率解释。
