# 已验证功能与最小脚本

## 运行方式

构建/回归：

```powershell
mvn -pl testbenchTbaGapp -am test
```

CLI 默认链在完整 reactor 安装/打包后使用 `de.gaalop.cli.Main --cli -i file.clu -a cga -o out`；插件由 ServiceLoader 获取。下表的 E2E 是本轮 188-test reactor 中同类脚本确实经过 parser→algebra→TBA/GAPP→测试 codegen/interpreter，不代表所有生产 backend。

| 能力 | 最小脚本 | algebra | 状态/结果 |
|---|---|---|---|
| 标量赋值/输出 | `a=1; b=2; ?c=a+b;` | cga | E2E；输出标量 3 的等价表达式 |
| basis/multivector | `?m=e1+2*e0+3*e1^e2;` | cga | E2E；见 `CoefficientTest` |
| GP | `?g=e1*e1;` | cga | E2E；product tests 36 cases |
| OP | `?o=e1^e2;` | cga | E2E；outer product tests 36 cases |
| IP | `?i=e1.e1;` | cga | E2E；inner product tests 36 cases |
| reverse | `?r=~(e1^e2);` | cga | E2E；`TrafoTest` 使用 sandwich/reverse |
| dual | `?d=*(e1^e2);` | cga | E2E 同类；通过 cga `Dual` 宏 |
| coefficient | `?a=coefficient(e1+2*e0,e0);` | cga | E2E；期望 2，见 `CoefficientTest` |
| macro | `M={ _P(1)+_P(2) } ?x=M(1,2);` | cga | E2E；arity/局部变量测试覆盖 |
| math | `?r=cos(0);` | cga | E2E；期望 1，`TrigonometricFunctions` |
| CGA point | `?p=createPoint(x,y,z);` | cga | E2E 同类；宏展开为 CGA point |
| output marker | `a=4; ?a;` | cga | E2E；`OutputCountTest` |

## 静态确认但不应伪称 E2E

- grade extraction：没有脚本语法；可用 `coefficient` 逐 blade 组合，但这不是 grade operator。
- inverse：division lowering 产生 `INVERT`，标量路径已覆盖；任意 multivector inverse 未建立跨空间 E2E 证据。
- condition：negative test 的 `if(...)` 产生解析错误，结论为不支持。
- 自定义代数：已静态确认加载器路径和 `algebraDefinitionString`；本轮没有新增外部代数定义测试夹具，故标记为“未验证”。

## 仓库脚本扫描

仓库实际 `.clu` 文件共 11 个，全部是内置 algebra 的 `macros.clu`；没有 `.gaalop` 文件。它们在每次对应 algebra transform 时由 `AlStrategy.java:80-109` 解析。测试脚本主要以内嵌 Java string 存在，不能只按扩展名扫描。

| 文件组 | algebra | 主要语法 | 解析状态 | E2E |
|---|---|---|---|---|
| `algebra/.../2d/macros.clu` | 2d | Dual | 已随构建/相关路径解析 | 部分 |
| `.../3d/macros.clu` | 3d | Dual | 同上 | 部分 |
| `.../2dpga`, `3dpga` | PGA | 系数提取、对偶、归一化、退化积 | 解析器支持 | 部分；未逐宏调用 |
| `.../cga`, `cra` | 共形空间 | 点、转子、球、提取操作 | 解析器支持 | CGA 多项由测试覆盖 |
| `.../ccga`, `dcga`, `gac`, `qga` | 特殊高维模型 | 大量专用宏 | 构建资源有效；按需解析 | 未逐宏验证 |
| `.../sta` | 时空代数 | 对偶 | 解析器支持 | 本轮未验证 |

注意：`3dpga/createRotor` 内调用 `sin(half,1)`，而 MathFunction 文档称单参数；它可能被当作未知/宏调用，是需要专项复测的可疑点。
