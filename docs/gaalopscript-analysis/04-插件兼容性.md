# 插件兼容性

| 能力 | parser | algebra | optimizer | backend/visualizer | 结论 |
|---|---|---|---|---|---|
| 基础 assignment/output | CluCalc | definition required for GA | TBA/GAPP | 多数 codegen | 通用主路径 |
| `:` expression/color/IPNS/OPNS | CluCalc | 可展开 | 通常可遍历 | visualCodeInserter/visualizer/ganja/vis2d | 可视化插件依赖 |
| `?` output | CluCalc | 输出 blade 重写 | 决定活跃输出 | backend | 主输出约定 |
| `#pragma insert/return` | wrapper | 无核心代数意义 | metadata pass-through | 仅识别相应 metadata 的 backend | backend dependent |
| math functions | 任意函数先作 MacroCall | 未命中宏后由中端识别 | TBA/GAPP 支持集不同 | 需函数名映射/import | 逐后端确认 |
| custom macro | CluCalc | `AlStrategy` 解析、查递归、内联 | 看到展开后 DFG | 与展开结果相关 | 推荐可移植扩展机制 |
| 未知外部调用 | 解析器支持 | 记录为未知调用 | 部分处理过程可能保留 | 后端可能原样发出或拒绝 | 不算端到端通用支持 |
| control-flow IR | 无脚本入口 | N/A | TBA 明确有 control-flow 拒绝路径 | 后端差异大 | GAALOPScript 不支持 |

CLI 默认链见 `cli/Main.java:20-75`：cga、CluCalc、globalSettings、visualCodeInserter、algebra、TBA、C++。`--gapp` 将 optimizer 切成 GAPP；所有 stage 也可按插件类名替换。

后端注册由每模块 `src/main/resources/META-INF/services/de.gaalop.CodeGeneratorPlugin` 完成。根 reactor 当前列出 C++、C#、Java、DOT、GAPP/OpenCL、compressed、Verilog、LaTeX、Visualizer、Rust、Mathematica、Julia、Gaalet、Vis2D、Ganja、Matlab、Python 等。存在模块不等于每个节点均支持；`DefaultCodeGeneratorVisitor` 覆盖常规标量 DFG，各专用 visitor 仍需逐项审计。

本轮实测主链覆盖 TBA、GAPP、Java 测试代码生成器和可视化测试；没有把 18 个生产后端对所有特征做笛卡尔积测试，相关单元格应视为“未验证”。
