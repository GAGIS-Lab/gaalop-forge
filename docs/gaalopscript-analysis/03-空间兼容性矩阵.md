## 内置代数定义

`algebra/.../definedAlgebras.txt` 与资源目录提供 `2d, 3d, 2dpga, 3dpga, cga, cra, sta, ccga, dcga, gac, qga`。PGA 的 `e0=0`；CGA 通过 `ep=+1, em=-1` 与 base change 提供 `e0/einf`；STA 签名为 `(+---)`。源码没有名为“HGA”或通用 Quaternion algebra 的独立资源；`qga` 是 quadric geometric algebra，不能按名称误报为 quaternion。

## 约束

- 维数：`AlStrategy.createBlades:254-263` 显式生成全部 `2^n` blades；CCGA 17 维意味着 131072 blades，存在明显内存/时间风险。
- 度量：definitions 可含正、负、零平方；GP/IP 使用签名/乘法表。除法、Normalize 与 pseudoscalar inverse 没有统一静态可逆性检查。
- 命名：核心 parser 不硬编码 `e1/e0/einf`；模型宏大量硬编码。换名的 custom algebra 仍可用核心运算，但这些宏会失效。
- CGA：up/down、sphere、point pair extraction 均是 cga `macros.clu` 普通宏，没有 AST 专用节点。
- PGA：退化 dual/reverse/regProd 由 2dpga/3dpga 宏逐 blade 定义，不能把普通 pseudoscalar inverse 假设套用到它们。
