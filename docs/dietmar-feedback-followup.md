# QuantumGAALOP 集成事项

## 已落实

统一 GAALOP 命名，量子页面使用 QuantumGAALOP。新工作区默认 QCA；已有草稿保留代数。Open 更新脚本和函数名，Save 使用文件授权或下载回退，Copy code 复制生成文本。量子页面通过 Help 说明计算方式。QCA 已扩展到 1–5 qubit。

MATLAB 生成器支持数值与符号输入，覆盖中间数组和多个输入输出。Python 生成器提供按需数学导入和数值数组支持。对应验证见各生成器文档。

## 量子博弈案例

开展 Jaroslav 案例集成需要原始论文、`.gs`、GAALOP 导出的 `.m`、手工修改后的 `.m`、输入参数及预期概率和收益。收到这些材料后，可逐项比较修改，确定自动生成规则和验收用例。

MATLAB 的复数单位与几何代数元素 `i=ei1^ei2` 需要通过系数表示建立明确映射。保留 `i` 输入、在脚本中定义几何元素和使用 MATLAB 复数分别代表不同计算方式，案例核对时应记录该选择。
