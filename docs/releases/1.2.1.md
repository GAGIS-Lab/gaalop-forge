# 1.2.1

发布日期：2026-10-26。镜像：`gagislab/gaalop-forge:1.2.1`，平台 Linux x86_64。

## 恒零输出

修复 `?z=0;`、`?z=e1.e2;`、零值与非零值混合输出，以及显式选择和返回模板引用的零系数。
稀疏优化仍可移除内部零系数；代码生成阶段恢复对外必需的赋值。GAPP 在指令装饰前恢复输出，保留 reset 指令。

- Python 不再生成 `Tuple[]`、空返回项或未替换的返回占位符。标量和 NumPy 数组模式都保留零输出。
- C#、Java、C/C++、Rust、Julia、MATLAB、Mathematica、compressed C/C++、gaalet 和 CLUCalc 的输出声明或赋值保留。
- C/C++、C# 数组模式及 Rust 清零调用方传入的输出缓冲区，避免未写系数保留旧值。
- OpenCL 为全零多向量生成已初始化的合法标量；常数赋值计入存储大小，并生成数值字面量。
- Ganja、GAPP、LaTeX、DOT 纳入真实编译链检查。没有改动代数定义、乘法表或示例公式。

未指定阶数或返回分量的全零多向量采用标量零作为规范稀疏表示；不会推测已经被优化消除的原始阶数。
显式选择或返回模板指定的分量则按原身份补零。稀疏接口可能因此增加此前错误遗漏的返回项。

## 独立运行生成文件

先用 `mvn -pl gaalop-rest -am test -Dtest=ZeroOutputServiceTest -Dsurefire.failIfNoSpecifiedTests=false -Dgaalop.zero.fixtureDir=/absolute/evidence/generated` 导出生成文件。
在 Windows 使用 PowerShell 7，并将属性中的路径改成实际绝对路径。

运行 `uv run --locked --project codegen-python/src/test/python gaalop-rest/src/test/python/zero_output_runtime.py python --evidence /absolute/evidence`。
将 `python` 改成 `java` 或 `csharp` 可用已安装的 JDK / .NET 8 检验生成代码。
`matlab_prepare` 生成 MATLAB 检验脚本，在该目录运行 `matlab -batch check_zero_outputs`。

C/C++、Rust、OpenCL、compressed C/C++ 检验使用一个具备 g++、rustc、clang 的隔离容器；
将 evidence 目录挂载到容器 `/work`，并用 `--tools-container` 指定容器名。
`julia` 使用 `--julia-image` 指定的 Julia 1.10 容器；`ganja` 使用本机 Node 做语法检查。
这些运行环境不属于应用镜像依赖。测试容器保留供维护者检查和清理。
