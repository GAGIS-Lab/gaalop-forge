# 1.2.0

发布日期：2026-10-21。镜像：`gagislab/gaalop-forge:1.2.0`，平台 Linux x86_64。

## 工作台

- GAALOPWeb 与 QuantumGAALOP 使用独立 HTML 入口、启动模块和草稿；顶部导航保持固定间距。
- 量子新工作区默认 QCA，恢复已有草稿时沿用原代数。
- Open 按文件名更新函数名；Save 写入授权文件或下载副本；Copy code 复制生成文本。
- 传统三维预览在无滑块时使用单行布局，上下留白一致。
- 说明文字按当前工作流和验证范围整理；早期设计保存在 `docs/archive/`。

## 编译器

- QCA 支持 1–5 qubit 的代码生成与概率展示。QRA 保持 2–9 qubit 原生数值执行。
- MATLAB 按输入依赖初始化数值或符号数组，覆盖中间数组及多个输入输出。
- Python 补全数学函数映射与按需导入，覆盖标量及 NumPy 数组输出。
- REST 保留 400、405、415 等请求错误状态，并过滤桌面专用生成器。
- 默认构建面向 Web；桌面入口使用 `-Pdesktop`，共享数学回归继续保留。

## 部署

健康检查使用独立 Java 服务的 `/gaalop/api/v1/health`，加入启动等待、重试和 activation identity 检查，通过正常重启恢复连续的连接或服务端故障。集成 Docker 使用根 `/api/v1/health`。

构建说明见 [Docker 发布](../docker-release.md)，独立服务更新见[服务器部署](../../deploy/ubuntu/README.md)。
