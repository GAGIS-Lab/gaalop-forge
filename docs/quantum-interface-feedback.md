# QuantumGAALOP 界面反馈落实

2026-10-20，按用户确认的“现在可以做”范围更新：

- 页眉、跨工作区链接和浏览器标题使用 QuantumGAALOP / GAALOPWeb。
- 新用户默认 QCA。新增独立的当前代数存储键，切换和刷新后恢复选择；各代数仍使用既有草稿键。
- 迁移旧草稿时，只有一个有效代数草稿则恢复该代数；旧版本未记录活动代数，存在多个旧草稿时无法可靠推断最后选择，因此使用 QCA，保留全部草稿。存储不可用时仍能编辑和运行。
- 两个工作区的 Upload 改为 Open。打开 .gs/.txt 时以文件名（去掉扩展名）设置 Function Name；非法标识符保留显示并要求修正后运行，不静默改写文件名。
- 量子工具栏移除 Optimization。Help 说明 QCA 的 TBA 符号编译与独立可视化求值、QRA 原生数值执行、quantum bit geometric algebra 的可视化限制。
- Copy code 提供复制到剪贴板的说明，复制成功显示 Copied。生成文件仍按“函数名＋语言扩展名”命名，不改变保存目录行为。

验证：四项前端脚本检查和 pnpm build 通过。浏览器验证新用户默认 QCA、切换 QRA 后刷新恢复、打开 bad-name.gs 后提示并拦截运行、打开 qca_feedback.gs 后自动填写函数名并运行成功，实际下载为 qca_feedback.m。Copy code 返回 Copied；自动化工具使用独立虚拟剪贴板，无法读取页面原生剪贴板内容，未将虚拟剪贴板读回视为产品复制结果。

2026-10-21 补齐此前遗漏的保存流程。按用户最终要求，两个工作区仅保留独立 Open、Save 按钮，生成代码区仅保留独立 Save，不显示下拉箭头及附加菜单。支持授权写回、独立文件句柄、取消及写入错误处理；生成文件绑定本次运行的函数名与语言。15 组文件流程测试、四项既有前端检查和 pnpm build 通过，并实际验证浏览器打开、脚本下载内容及 MATLAB 扩展名。自动保存到 .gs 目录仍未实现。详见 [Open/Save 维护说明](browser-open-save.md)。
